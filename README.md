# Euclidean Distance Visualizer

Course assignment exploring Euclidean distance, vector similarity, and data visualization with Matplotlib and interactive Plotly plots.

## Overview

This repository contains a Jupyter Notebook that demonstrates concepts of Euclidean distance, vector similarity, and advanced data visualization techniques. It combines mathematical computations with both static (Matplotlib) and interactive (Plotly) visualizations to help understand geometric relationships in multi-dimensional spaces.

## Contents

- **vector.ipynb** - Main Jupyter Notebook with Euclidean distance calculations, vector operations, and visualizations

## Features

- 📐 Euclidean distance calculations
- 🎯 Vector similarity metrics
- 📊 Static visualizations with Matplotlib
- 🎨 Interactive plots with Plotly
- 📈 Multi-dimensional data exploration
- 💻 Clear explanations and examples

## Concepts Covered

### Euclidean Distance
The Euclidean distance is the straight-line distance between two points in space, calculated using the formula:
```
d = √[(x₂-x₁)² + (y₂-y₁)² + ... + (zₙ-z₁)²]
```

### Vector Similarity
Various methods to measure how similar two vectors are, including:
- Euclidean distance
- Cosine similarity
- Manhattan distance

### Data Visualization
- **Matplotlib** - Static, publication-quality plots
- **Plotly** - Interactive visualizations with hover information and zoom capabilities
